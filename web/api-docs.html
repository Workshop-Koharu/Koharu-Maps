개요

Koharu Maps API는 외부 상용 지도 서비스(Google, Naver, Kakao, Mapbox 등)에 의존하지 않고, 순수 자체 구현된 수학적 좌표계 변환, R-Tree/QuadTree 공간 인덱스, A* 도로망 그래프 라우팅 엔진, 역색인 지오코딩 엔진을 통해 모든 지리정보 연산을 제공하는 독립형 RESTful API 서비스입니다.

인증 방식: API 요청 시 헤더 X-API-Key: YOUR_API_KEY 또는 쿼리 파라미터 ?api_key=YOUR_API_KEY를 전달할 수 있습니다. 무료 키 없이도 기본 호출이 가능합니다.

1. 장소 검색 및 지오코딩 (Search & Geocoding)

GET /api/v1/search 장소 및 주소 Forward 검색

한글 및 영문 명칭, 주소, 도로명 검색어를 분석하여 좌표 및 매칭 점수가 포함된 장소 목록을 반환합니다.

파라미터타입필수설명
qstring예검색 키워드 (예: "강남역", "광화문", "세종대로")
limitint아니오결과 최대 개수 (기본값: 10)
center_lonfloat아니오현재 뷰포트 중심 경도 (거리 가중치 계산)
center_latfloat아니오현재 뷰포트 중심 위도 (거리 가중치 계산)
응답 예시 (JSON):
{
  "status": "success",
  "query": "강남역",
  "count": 1,
  "results": [
    {
      "id": "poi_6",
      "name": "강남역",
      "category": "교통/상업",
      "address": "서울특별시 강남구 강남대로 396",
      "location": { "lon": 127.0280, "lat": 37.4980 },
      "score": 31.0
    }
  ]
}
GET /api/v1/reverse-geocode 역지오코딩 (좌표 -> 주소)

지정된 위도와 경도에서 가장 가까운 도로명 주소 및 행정구역, 랜드마크를 반환합니다.

파라미터타입필수설명
lonfloat예경도 (Longitude, WGS84)
latfloat예위도 (Latitude, WGS84)
max_dist_mfloat아니오최대 허용 탐색 반경 (미터, 기본값: 3000)

2. 네비게이션 및 길찾기 (Routing & Navigation)

GET /api/v1/route 자체 도로망 기반 A* / Dijkstra 경로 탐색

출발지와 도착지 좌표를 도로망에 스냅한 후, A* 알고리즘을 통해 최단거리 또는 최단시간 경로와 턴바이턴 안내를 계산합니다.

파라미터타입필수설명
startstring예출발 좌표 'lon,lat' (예: "126.9768,37.5750")
targetstring예도착 좌표 'lon,lat' (예: "127.0280,37.4980")
algorithmstring아니오'a_star' (기본값) 또는 'dijkstra'
weightstring아니오'time' (예상시간 기준) 또는 'distance' (거리 기준)
응답 예시 (JSON):
{
  "status": "success",
  "algorithm": "a_star",
  "start": { "query": [126.9768, 37.575], "snapped_node_name": "광화문교차로" },
  "target": { "query": [127.028, 37.498], "snapped_node_name": "강남역사거리" },
  "route": {
    "distance_m": 10540.2,
    "duration_sec": 780.5,
    "duration_min": 13.0,
    "coordinates": [[126.9768, 37.575], [126.977, 37.566], ...],
    "instructions": [
      { "type": "depart", "message": "세종대로(으)로 출발합니다.", "distance_m": 1000.5 },
      { "type": "turn-right", "message": "강남대로 방면으로 우회전입니다.", "distance_m": 1500.0 },
      { "type": "arrive", "message": "목적지에 도착했습니다." }
    ]
  }
}

3. 벡터 타일 및 공간 피처 (Tiles & Features)

GET /api/v1/tile/{z}/{x}/{y} 타일 단위 정규화 벡터 피처 서빙

표준 타일 피라미드 좌표 (z, x, y) 경계로 클리핑된 레이어별 기하 객체를 반환합니다.

GET /api/v1/features 바운딩 박스 공간 질의 (Spatial Query)

R-Tree/QuadTree 공간 인덱스를 통해 지정된 BoundingBox 범위 내의 모든 지리 객체를 조회합니다.

파라미터타입필수설명
bboxstring아니오"min_lon,min_lat,max_lon,max_lat" (기본: 서울 수도권)
zoomint아니오LOD 필터링용 줌 레벨 (0~24)
limitint아니오최대 반환 개수 (기본값: 500)
GET /api/v1/export/kmap 독립형 KMAP 바이너리 아카이브 패키지 다운로드

SHA256 무결성 검증 헤더가 포함된 자체 오프라인 .kmap 바이너리 파일을 다운로드합니다.

4. API 키 및 인증 (API Keys & Auth)

POST /api/keys 무료 API 키 발급 (JWT Bearer 인증 필요)
GET /api/keys 발급된 API 키 목록 및 사용량 조회
DELETE /api/keys/{key_id} API 키 삭제
